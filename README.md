# 舆情链接巡查 Skill

从用户提供的 Excel 或 CSV 舆情表读取链接，由 AI 逐条访问目标内容，检查是否仍可访问，并在保留原表的基础上输出逐条标记结果和汇总。

完整规则见 [SKILL.md](skills/public-opinion-link-check/SKILL.md)，安装与环境要求见 [使用说明](skills/public-opinion-link-check/使用说明.md)。

## 功能

- 提取单元格中的普通链接、超链接及 HYPERLINK 公式内的链接，不执行表格公式。
- 保留原始记录、历史状态、工作表和行号；拆分同一行中的多个目标链接。
- 核对目标内容身份，记录实际落地链接、访问时间、状态及判断依据。
- 保留原表的大致格式，新增逐条状态、说明及时间，并形成数量和平台汇总。
- 保存可续查记录，遇到无法完成的项目如实说明。

## 使用

取得本私有仓库访问权限后，可将以下请求交给 Codex：

> 请安装仓库 https://github.com/wuyh325666/public-opinion-link-check-skill 中 skills/public-opinion-link-check 路径下的 Skill，并检查是否能识别。

提供需要核查的表格后，输入：

> 使用 public-opinion-link-check，逐条核查这份舆情表的帖子链接，保留原始状态和原表格式，输出逐条标记版 Excel 及汇总。保留实际访问依据和核查时间，无法完成的项目单列说明。

每位使用者需要自己的浏览器连接和平台登录状态。读取 `.xlsx` 需要 Python 3 和 openpyxl；Excel 输出依赖当前 AI 环境中的表格能力。配套脚本负责链接提取、证据校验及本地报告，不会自行浏览网站，也不代表无需登录的无人值守爬虫。

## 判定与限制

- 微信视频号按既定流程标为“待复核（工具限制）”，不自动打开或转发给联系人。
- 其他平台按本 Skill 的业务验收口径保留“已删除（无法正常访问）”标签，同时记录真实原因。该标签不等于平台明确确认物理删除。
- 未访问或缺少链接的记录不计入删除；工具明确禁止的访问不可绕过。
- 不执行举报、删帖、发送消息或代替平台处理内容。

## 文件

```text
skills/public-opinion-link-check/
├── SKILL.md
├── 使用说明.md
├── scripts/
│   ├── prepare.py
│   ├── report.py
│   └── self_test.py
└── assets/
    ├── 空白模板.csv
    └── 模拟样例.csv
```

`prepare.py` 生成待核查项；AI 保存真实访问证据后，由 `report.py` 校验并生成 JSON 和 HTML 汇总。最终 Excel 由当前环境的表格工具另行生成。

仓库只包含通用流程、脚本、空白模板和虚构样例，不包含真实客户表格、核查结果、截图、登录资料或缓存。仓库保持私有，同事需获得访问权限；上传不会自动安装或同步到同事设备。
