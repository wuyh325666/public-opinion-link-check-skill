# 舆情链接核查 Skill V0.5

适用于支持本地 Skill、文件读取和浏览器操作的 Codex 环境。安装完成不代表已具备平台登录权限。

## 安装与使用

解压后将 public-opinion-link-check 文件夹放入自己的 Codex skills 目录（默认 ~/.codex/skills；Windows 为用户目录下 .codex/skills）。重新打开任务，输入：

> 使用 $public-opinion-link-check，逐条核查这份舆情表的帖子链接，保留原状态，输出标记后的 Excel 和汇总。无法确认的单独列出。

也可以把本文件夹交给 Codex，请它安装到当前用户的 skills 目录。不要覆盖同名旧版本而不保留备份。

每位同事需有可用的浏览器连接和自己的平台登录状态。Python 3 用于台账和报告处理；读取 xlsx 需要 openpyxl，优先使用 Codex 自带运行环境，缺少时由 Codex 协助配置。Excel 导出使用当前环境的表格能力。

空白模板在 assets/空白模板.csv，可直接用 Excel 打开。已有监测台账也能使用，无需改成固定列顺序。默认核查帖子本身，评论核查需另附评论定位信息。

微信视频号统一标记“待复核（工具限制）”，本流程不自动访问。其他平台原链接实际访问后无法正常提供目标内容，或落地内容ID与原目标不同，按验收口径标记“已删除（无法正常访问）”。此标签属于业务判定，明细保留实际跳转依据；首页跳转、权限限制、内容不存在等无法访问情况也按此口径归为删除，但未访问或缺少链接不能算删除。

当前版本包含通用流程、链接提取和报告校验脚本。各平台页面可能变化；遇到验证码、登录限制或缺少客户端操作能力，需人工接续。它不是无需登录、无人值守的爬虫。

共享 ZIP 仅用于分发安装，不会自动同步到同事设备。后续版本用同一分发位置统一更新，并由各同事安装。真实业务核查结果单独交付，不进入共享包。
